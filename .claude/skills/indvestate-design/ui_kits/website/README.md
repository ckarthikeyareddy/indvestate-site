# INDVESTATE website UI kit

Click-through of the brand site, composed from the design-system bundle.

- `index.html` — app shell, routing (persisted in localStorage), theme toggle.
- `kit-shared.jsx` — Icon (Lucide), Section, Reveal, MediaFrame, CountUp, Checklist, Footer, sample drop data.
- `screen-home.jsx` — hero with word-cycle + corridor map, count-up strip, live drop + risk memo, services, inside list + founder note.
- `screen-drop.jsx` — Drop 01 detail: status strip, gallery, tabs (risk memo / documents / location), sticky price panel, disclaimer.
- `screen-inspection.jsx` — 3-step booking: property → slot → Razorpay (mocked) → booked stamp.
- `screen-nri.jsx` — NRI desk: live time-zone clocks, desk services, bilingual block, NRI inside-list form.

No product source was supplied; screens are designed from the brand brief, not recreated from an existing site. Photography slots are placeholder frames.
