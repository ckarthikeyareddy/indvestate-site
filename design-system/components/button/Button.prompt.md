Square-cornered action button; primary (saffron) is the single saffron element on a screen.

```jsx
<Button>Join the inside list</Button>
<Button variant="secondary" iconRight="↗">WhatsApp the desk</Button>
<Button variant="ghost" mono>Read the risk memo</Button>
```

- Sizes sm 36 / md 44 / lg 52. Primary hover = lighter saffron + glow-saffron; press = darker, no glow.
- Never a signal-coloured button. Never rounded. Labels say what happens: "Book an inspection", not "Get started".
