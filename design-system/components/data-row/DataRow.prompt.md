A mono label/value pair on a hairline rule — the atomic unit of property data.

```jsx
<DataRow label="Survey No." value="214/A, 214/B" />
<DataRow label="Encumbrance" value="EC 1983–2026 · clear" tone="verified" />
<DataRow label="Coordinates" value="17.3850° N, 78.4867° E" tone="signal" />
```

Figures are never tracked; labels always are. Use `stack` in 3-up grids.
